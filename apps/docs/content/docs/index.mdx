Welcome to the official documentation for the School OS monorepo.

This project combines modern tooling and a production-minded structure so you can ship web,
mobile, and API apps from one workspace.

## Why School OS

School OS is a **trust engine for Pakistani school networks** — mobile-first, WhatsApp-native,
starting with Smart Attendance and parent alerts, not a generic ERP. Built for campuses in
Karachi, Lahore, and Islamabad, with **Aga Khan Schools (AKES)** as the primary design reference.

This docs site covers both **product vision** and **engineering** for the monorepo.

- Trust-first product: scan → WhatsApp alert → dashboard → AI signals (with approval)
- Target market: Pakistani school networks (~200–2K students per campus)
- Monorepo with Turborepo workspaces (`apps/*`, `packages/*`)
- Bun-first package and task management
- Shared TypeScript and UI packages across apps
- Built-in quality gates with oxlint, oxfmt and Lefthook
- Multi-platform: Web, Mobile, Nest API, Docs, optional AI + Rust
