The tour signs in as the principal, then as a teacher, using the seeded demo school. It was
recorded at 1920×1200 from the running app; nothing in it is mocked.

## What ships today

The web app (`apps/web`) is rebuilt to the School OS Figma file on the `@rabtx/ui` tokens. Every
screen reads live data from the Nest API. Features whose backend does not exist yet show an honest
empty state instead of sample data.

### Everyone

| Screen | Route | What it does |
| --- | --- | --- |
| Sign in | `/login` | Password, passkey, magic link or Google (domain allowlist); TOTP MFA |
| ⌘K search | any page | Jump to pages, classes and students |
| Notifications | top bar | Recent alerts for the signed-in member |
| Account | `/admin/account/profile`, `/admin/account/security` | Profile; password change (rotates the current session), passkeys, MFA and sessions |

### Principal and leadership

| Screen | Route | What it does |
| --- | --- | --- |
| Approvals | `/admin/approvals` | Leave from parents, attendance and marks changes from teachers. One request at a time, oldest first: what changes if you approve, approve (⌘↵) or decline with a reason, undo for 15 seconds, then the next. The sidebar shows how many wait |
| Messages | `/admin/messages` | Conversations with families: who needs a reply, the thread with read receipts, reply or start one with a guardian. Teachers see their own classes |
| Notices | `/admin/notices` | Notices to all parents, some classes, staff or everyone: drafts, send now, who has read each one. Teachers write to their own classes and send through approvals |
| Dashboard | `/admin` | Students, attendance today, late arrivals, homework due, attendance trend, check-in method, today's check-ins |
| Students | `/admin/students` | Search and filter, profile panel with attendance, guardians, enrolment and ID card, CSV export |
| Guardians · ID cards | `/admin/guardians`, `/admin/students?view=cards` | Guardian directory and printable student ID cards |
| Attendance report | `/admin/reports?tab=attendance` | Rate by class and weekday, late arrivals, unexplained absences, follow-ups |
| Timetable | `/admin/timetable` | Week grid per class with periods, rooms and teachers |
| Settings | `/admin/settings` | School, campuses, attendance rules, communication policy, members and roles |
| WhatsApp | `/admin/settings/communication` | Connect WhatsApp (sandbox locally, Meta Cloud API in production), the last day's deliveries and a delivery log; messages and notices go to guardians' WhatsApp with SMS fallback, and replies come back into Messages |
| Attendance rules | `/admin/settings/attendance` | Roll call close, late after and grace, auto-absent, gate scan rules, teacher edit window and absence alert timing, saved as versions |

### Teacher

| Screen | Route | What it does |
| --- | --- | --- |
| Teacher home | `/admin` | Next class, roll call status, answers to review, homework due, today's lessons, students absent several days running |
| My classes | `/admin/my-classes` | Today / This week / All classes with attendance meter and trend |
| Roll call | `/admin/attendance` | Present, late, absent or excused per student, with guardian, check-in time and method; late and absence tabs. Once the edit window closes, a student's menu asks the principal for a change |
| Homework | `/admin/homework` | Assigned and draft homework with submission bars, AI draft helper |
| Check answers | `/admin/homework?tab=submissions` | Mark each answer in a side panel: marks, comment, excused, not handed in, save and next |
| Marks | `/admin/gradebook` | Every test and homework for a class subject: latest homework, tests, homework average, trend, overall and grade, CSV export |
| Report cards | `/admin/gradebook?tab=report-cards` | Subject grades per student with attendance in a side panel |
| Tests & exams | `/admin/assessments` | Tests and quizzes with date, duration and results; side panel to publish, close or enter marks. Once a test is closed, teachers send mark changes to the principal |
| Test planner | `/admin/test-planner` | The term's test calendar |

### Parent

| Screen | Route | What it does |
| --- | --- | --- |
| Messages | `/admin/messages` | Write to the school about a child and read replies |
| Notices | `/admin/notices` | Notices from the school, newest first |
| My children | `/admin/my-children` | Each child's ID card, homework and attendance; ask for leave and see whether it was approved |

## Recording the tour again

The tour is scripted with Playwright against the local stack (`bun run dev` with the seeded
database). It captures frames through the Chrome DevTools screencast at 4/3 device pixel ratio and
encodes them with ffmpeg (`libx264`, CRF 18). Keep the file in `apps/docs/public/media/` so the
docs site and the README share one copy.
